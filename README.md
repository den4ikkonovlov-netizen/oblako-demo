# Облако — демонстрационный сайт

Самостоятельный проект студии праздников «Облако», Северодвинск.

## Локальный запуск

Из этой папки: `python -m http.server 8767 --bind 127.0.0.1 --directory dist`.
Открыть http://127.0.0.1:8767/.

Статический HTML/CSS/JavaScript. Первый экран — авторская растровая сцена с послойным CSS/JS-параллаксом. WebGL и загрузка ES-модулей не требуются. Все шрифты и используемые фотографии также локальные. Backend и платёжные функции отсутствуют.

План праздника сохраняет только ID выбранных услуг в localStorage. Дата, возраст и заметки остаются в памяти формы. Сайт подготавливает текст для ручной отправки в ВК; сам сообщения не отправляет и не обещает бронирование.

## Контент

Источник: https://vk.ru/oblako_severodvinsk, услуги https://vk.ru/uslugi-216535130, альбом https://vk.ru/album-216535130_287574215, отзывы https://vk.ru/reviews-216535130. Прочитано 30.10.2026.

Главный телефон сообщества +7 909 551-55-16. Адрес из сообщества: Железнодорожная, 3А. Старые справочники содержат другой адрес и телефон — они не использованы.

Цены взяты из актуального текста карточек ВК, а не из ценников на старых рекламных изображениях. Состав пакетов переписан без добавления неподтверждённых услуг. Герои — пожелания к программе, их стоимость не суммируется с пакетом автоматически. Условия аренды без программы: будние дни; единица тарифа не подтверждена, не выдумана.

Три коротких фрагмента реальных отзывов ведут на источник. Никакие новые отзывы и числовые показатели не выдуманы. Рейтинг 5,0 и 20 отзывов наблюдались в сообществе.

## Движение и доступность

Движение фона использует сглаживание по времени кадра, паузу вне экрана/скрытой вкладки и prefers-reduced-motion. Карточки сохраняют неподвижную область наведения. Внутренние элементы движутся плавно без изменения layout. Модальные окна используют native dialog, доступны клавиатурой. У изображений героев object-fit:contain.
